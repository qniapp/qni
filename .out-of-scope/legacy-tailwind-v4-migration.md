# 旧 Qni だけを対象とする Tailwind v4 移行

旧 Qni の Tailwind v3 環境を v4 に移行する作業は対象外とする。

## 理由と範囲

WebGPU 版を次の Qni とし、開発・公開の対象を WebGPU 版へ移す。
新機能は `qni-webgpu`、チュートリアルの改善は `qni-tutorial-webgpu` を対象とする。
この方針に沿わない旧版だけの Tailwind 更新は進めない。時間や費用を理由とする一時的な延期ではない。

移行期間中、旧 Qni の変更は移行を妨げる問題の修正と必要なセキュリティ保守に限る。
これらは個別に判断する例外であり、旧版の Tailwind 環境全体を v4 に移行する承認ではない。
旧版を直ちに放棄する判断でもなく、既存コンポーネントを削除する必要もない。

この決定はリポジトリの改名・移動・削除、デプロイ変更、アーカイブを承認しない。
`elements` や各パッケージの外部利用者と旧 URL の互換性は調査が必要であり、影響がないとは扱わない。
